# Agent 开发总入口

## 执行顺序

1. **入场判档**（按 SKILL.md「入口分诊」）：写出判档行，说明依据；判不清先问用户。
2. **轻量模式** → 直接加载对应规范写码 → 过 `check-agent-standards` → 四行交付。流程结束。
3. **完整流程** → 判断项目状态：

| 项目状态 | 起手步骤 |
|---|---|
| 从零新建 | 0.0 → 1.1 |
| 存量 agent 首次接入 | 0.5 → 1.1 |
| 已接入规范，新增能力 | 1.1（有旧产物先做变更影响） |
| 已有产物改架构 | 回 3.1，并登记产物同步 |

4. 按 0.0/0.5 → 1.1 → 1.2 → 2.1 → 3.1 → 3.2 → 4.1 → 5.1 → 6.1 → 7.1 顺序推进，**每步产出后停下等确认**。

## 硬规则

- 禁止跳步：没有 2.1 不得进 5.1；没有 3.2 不得实现工具；6.1 未过不得进 7.1
- 每步产物落盘前先展示摘要给用户确认，确认后写入
- 一次只推进一个步骤，不预生成后续产物

## 首句输出格式

> 判档：完整流程（依据：新建 agent，涉及工具与检索，需对外承诺效果）
> 项目状态：从零新建
> 下一步：0.0 agent 项目初始化，将检查 11 项基础设施，预计产出 0.0-agent项目初始化.md
