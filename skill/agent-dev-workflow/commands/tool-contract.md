# 工具清单与契约（3.2）

## 做什么

产出 `3.2-工具清单与契约.md`，加载 `agent-tool-standards`。每个工具一张卡，九字段齐全：名称、描述、参数、副作用等级、幂等、权限、错误语义、超时、来源。

## 执行规则

1. 一个工具一件事；名称用动词+名词，禁止 doEverything 式聚合工具
2. 描述里必须写「什么时候该用 / 什么时候不该用」，这是模型选工具的唯一依据
3. 写类工具必须给幂等键与去重窗口
4. 错误语义必须可被模型读懂并自我修正（禁止只返回 HTTP 500）
5. 工具总数超过 15 个，必须写明分组或检索式选择策略
6. MCP 工具与本地工具分别标注，并写明超时与重试归属

## 完成标准

- [ ] 每个工具九字段齐全
- [ ] 副作用等级全部标注，高危工具有人工确认开关设计
- [ ] 工具数超限时有选择策略
- [ ] 用户已确认（未确认不得实现工具）
