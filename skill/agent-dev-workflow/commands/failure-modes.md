# 失败模式清单（1.2）

## 做什么

产出 `1.2-失败模式清单.md`，按六类逐条列：幻觉、串工具、死循环、越权、成本失控、上下文溢出。每条必须挂到具体规范技能（对照 `references/完整流程.md` 1.2 节的映射表）。

## 每条必填

| 字段 | 说明 |
|---|---|
| 触发条件 | 什么输入/什么状态下会发生 |
| 预期行为 | 正确时应该怎样 |
| 观测方式 | 从哪个日志字段/指标能看出来 |
| 挂载规范 | 由哪个规范技能约束 |
| 评测样本 | 2.1 要补哪条样本（可暂留空，2.1 时回填） |

## 执行规则

- 六类逐类核对，某类确实不适用要写明理由，不能整类跳过
- 允许追加本项目特有失败模式，但不得删减六类
- 每条都要能对应到"能观测"，观测不到的失败模式等于没写

## 完成标准

- [ ] 六类逐条有结论
- [ ] 每条有观测方式与挂载规范
- [ ] 用户已确认（未确认不得进 2.1）
