# 存量 agent 扫描（0.5）

## 做什么

四维度扫描，产出 `0.5-存量agent现状.md`：

1. 调用点清单（模型调用位置、封装层次、是否统一入口）
2. 提示词散落位置（硬编码几处、配置几处、有无版本）
3. 工具清单（schema 完整性、副作用分级、是否接 MCP）
4. 可观测现状（日志字段、trace、token 计量、评测集）

## 决策闸门（必须停下等用户拍板）

三选一，不得替用户选：

1. 全量改造 — 适合准备长期迭代
2. 增量对齐 — 新代码按新规范，旧代码不动
3. 只修当前问题 — 不引入规范

未选择不得进 1.1。

## 完成标准

- [ ] 四维度均有实际证据（文件:行号），无"大概""应该"
- [ ] 决策已由用户拍板并记录
- [ ] 已更新进度文件
