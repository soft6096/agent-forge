# 评测执行与需求覆盖（7.1）

## 做什么

按 2.1 口径执行评测，产出 `7.1-评测报告与需求覆盖.md`，加载 `agent-eval-standards` + `agent-ops-standards`。

## 必含五段

1. 各层数据集通过率与基线对比（涨/跌/持平 + 幅度）
2. 失败样本逐条归因，归到 1.2 的失败模式类别
3. 成本与时延数据（平均 token、单任务成本、P95 时延）与基线对比
4. 需求逐条覆盖：1.1 每条正向能力对应哪些代码、哪些样本
5. 未覆盖项与风险声明

## 执行规则

1. 评测集与阈值不得为了通过而临时调整；确需调整必须单独记录并说明原因
2. 失败样本必须给出真实输入与真实输出，禁止概括成"个别情况不理想"
3. 结论写成统计式（如"任务通过率 82/100，较基线下降 3 个点，集中在多工具串联场景"），禁止"效果良好"
4. 未达门禁 → 回 4.1 或 3.1，不允许只改提示词硬凑指标而不记录
5. 交付前确认 6.1 报告已存在且通过

## 完成标准

- [ ] 五段齐全
- [ ] 每层数据有样本数与通过数
- [ ] 失败样本有归因
- [ ] 门禁结论明确（达标/不达标）
- [ ] 用户已确认
