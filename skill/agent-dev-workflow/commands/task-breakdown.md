# 任务拆解（4.1）

## 做什么

产出 `4.1-任务拆解.md`，Phase 划分固定：

| Phase | 内容 |
|---|---|
| 0 | 基础设施：日志、trace、成本计量、超时、开关 |
| 0.5 | 公共组件：模型调用封装、工具注册器、上下文组装器 |
| 1 | **评测集建设（独立 Phase，不得并入编码）** |
| 2 | 核心链路：骨架与主循环 |
| 3 | 工具实现 |
| 4 | 记忆与检索（如涉及） |
| 5 | 安全与兜底 |
| 6 | 评测执行与调优 |

## 每个任务必填

输入、输出、验收标准（可机械判定优先）、依赖、预估工作量、完成标志（一行命令或一条可观测现象）。

## 执行规则

- Phase 1 不允许合并进 Phase 2，评测集必须先于主链实现完成
- 公共组件在 Phase 0.5 落地，后续使用点必须复用，禁止自留副本
- 完成标志必须可执行，不能写"功能正常"
- 超出 3.1 方案的任务不允许出现在拆解里

## 完成标准

- [ ] 八个 Phase 齐全（不适用的写"不涉及"并说明）
- [ ] 每个任务有完成标志
- [ ] 用户已确认（未确认不得进 5.1）
