# 评测口径与数据集（2.1）

## 做什么

产出 `2.1-评测口径与数据集.md`，加载 `agent-eval-standards`。六项必填：数据集分层、样本编写规范、指标口径、判定方式、回归基线、上线门禁。

## 数据集分层

| 层 | 规模 | 用途 |
|---|---|---|
| 冒烟集 | 5~15 条 | 每次改动必跑，覆盖主路径 |
| 回归集 | 只增不删 | 覆盖历史失败样本 |
| 黄金集 | 人工确认过答案 | 版本间对比 |
| 对抗集 | 按风险面 | 注入、诱导、越权、边界 |

## 执行规则

1. 指标至少含：任务通过率、工具正确率、平均步数、平均 token、P95 时延、单任务成本
2. 判定方式写明：精确匹配 / 规则断言 / 模型裁判。用模型裁判必须写裁判模型、rubric、与人工标注的一致性抽检比例
3. 每层数据集给出文件路径与样本数，不允许只写"将建立"
4. 1.2 的每条失败模式至少对应一条样本
5. 出现以下反模式直接打回：只有准确率一个指标、样本全由写码 agent 生成且无人工确认、没有回归集
