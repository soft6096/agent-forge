# 进度与断点（agent-progress）

## 执行

1. 定位模块版本目录：`docs/<模块>-v<版本>-<时间戳>/`；找不到 → 列出 docs/ 目录让用户选，附【AI 推荐】与理由，不猜。
2. 读取 `通用-模块进度与断点.md`；不存在则据已有产物补建。
3. 报告三件事：
   - 每步状态（已完成 / 待办 / 断点）
   - 当前断点停在哪个步骤、在等什么输入
   - 产物完整性核对：实际列目录比对，缺文件说明上一轮未落盘，先补
4. 询问是否从断点续跑，确认后从对应命令继续。

## 硬规则

- 有进度文件且显示未完成 → **禁止从 1.1 重跑**
- 架构变更（3.1 已确认后改主链路）→ 先做产物同步记录，再从 3.1 续跑
- 进度文件只记录流程位置，不替代产物内容
