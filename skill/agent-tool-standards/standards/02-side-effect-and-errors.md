# 02 副作用、幂等、权限、错误与超时

## 一、副作用分级（必须标注，不准留空）

| 等级 | 判据 | 例 | 约束 |
|---|---|---|---|
| 只读 | 不改变任何外部状态 | 查询订单、检索文档 | 可自由重试 |
| 写 | 改变状态但可补偿 | 创建工单、改地址 | 必须幂等键 |
| 高危 | 不可逆、涉及资金 / 权限 / 外部可见 | 退款、删数据、发券、发消息 | 幂等 + 人工确认开关 |

判定口诀：**能否在 10 分钟内靠反向操作完全恢复**。不能恢复的一律按高危处理。

分级要写进契约与代码常量，不能只写在文档里：

```python
class SideEffect(Enum):
    READ = "read"
    WRITE = "write"
    DANGEROUS = "dangerous"
```

## 二、幂等

### 什么算幂等（可核对）

- 有**幂等键**：`idempotency_key = f"{session_id}:{step_no}:{tool_name}:{biz_key}"`
- 有**去重窗口**：写明时长（建议 ≥ 任务最大时长），过期后可重复执行
- 落库有**唯一索引**兜底，不依赖"先查后写"

### 什么不算幂等（出现即返工）

- 写之前 `SELECT` 一次判重 —— 并发下两个请求都能通过
- 靠业务字段自然唯一（如订单号）但没建唯一索引
- 幂等键用随机 UUID 每步新生成 —— 等于没有
- 幂等键里不含业务键 —— 同一业务重复调用会产生多条记录

### 去重窗口与清理

| 项 | 要求 |
|---|---|
| 存储 | 幂等键表 / Redis，键值含结果摘要 |
| 窗口 | ≥ 任务最大时长 + 重试余量，写明数值 |
| 冲突返回 | 返回首次执行的结果（含 `duplicated: true`），不是报错 |
| 清理 | 定时任务按窗口删除，禁止无限增长 |

## 三、权限与租户边界

- 契约里写清：所需角色、租户隔离方式（行级 / 库级 / 前缀）
- 租户 id **从会话上下文取，不从模型参数取** —— 模型给的租户 id 一律不可信
- 越权返回 `permission_denied` 且**不泄露资源是否存在**
- 高危工具的人工确认是独立开关（默认开），归 `agent-safety-standards` 管，工具侧只负责暴露"这是高危"标记

## 四、错误返回语义

固定三段式，缺一不可：

| 段 | 内容 | 用途 |
|---|---|---|
| error | 机器可读错误码（有限枚举） | 骨架据此判定是否重试 |
| message | 人 / 模型可读一句话，含具体哪个值不对 | 模型自我修正 |
| hint | 下一步建议（可空） | 减少无效重试 |

禁用写法：

- `{"code": 500, "msg": "系统错误"}` —— 无可修正信息
- 直接把异常堆栈返回给模型 —— 泄露实现细节且无用
- 失败返回成功结构 + `success: false` 混在业务字段里 —— 骨架无法可靠判定

## 五、超时与重试归属

| 层 | 负责什么 | 禁止 |
|---|---|---|
| 工具 | 单次调用超时（默认 10s，长任务显式声明） | 工具内部自行重试 3 次 |
| 骨架 | 判定可重试性、重试次数与退避 | 对 `permission_denied` 重试 |
| 契约 | 声明是否可重试、是否幂等 | 写"视情况而定" |

可重试：网络超时、限流、5xx。不可重试：参数错误、权限错误、业务规则冲突。
