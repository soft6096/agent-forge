## 四、风险与假设

| 项 | 说明 | 应对 |
|---|---|---|
| 回放按原文匹配 | 换说法即命中不到录制，导致"看起来答非所问" | README 已写明；验证新说法需先补录制 |
| 条款库为本地模拟 | 真实检索质量未验证 | 接真实 RAG 时按 agent-rag-standards 重做召回评测 |
| 无回归集与黄金集 | 改动后只能跑冒烟，历史失败样本无法沉淀 | 每次真实失败即回填一条回归样本（只增不删） |
