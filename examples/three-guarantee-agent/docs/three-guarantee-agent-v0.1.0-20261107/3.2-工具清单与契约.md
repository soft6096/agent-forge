# 工具清单与契约 - three-guarantee-agent

> 使用说明：第 3.2 步产物。每个工具一张卡，九字段齐全；本文件未确认不得实现工具。
> 一条工具一件事；描述必须写「什么时候该用 / 什么时候不该用」——这是模型选工具的唯一依据。
> 写类工具必须有幂等键；错误语义必须可被模型读懂并自我修正。以下契约与 src/tga/tools/builtin.py 一致。

> [!IMPORTANT] 文档速览
>
> | 项目 | 内容 |
> | :--- | :--- |
> | **工具总数** | 4（本地 4 / MCP 0） |
> | **写类工具** | 1，有幂等键（session_id:tool:biz_key，窗口 7200s） |
> | **高危工具** | 1，需人工确认（approval_required 令牌通道） |
> | **选择策略** | 全量注入（4 个，未超 15 个上限，无需分组或检索式选择） |

## 一、工具总表

| # | 名称 | 用途 | 副作用 | 来源 | 超时 |
|---|---|---|---|---|---|
| 1 | get_vehicle_profile | 按 VIN 取车辆档案 | 只读 | 本地 fixture | 3000ms |
| 2 | query_warranty_period | 查零部件三包有效期 | 只读 | 本地 fixture | 3000ms |
| 3 | search_clause | 检索条款库并返回出处 | 只读 | 本地条款库 | 3000ms |
| 4 | submit_appeal_ticket | 提交三包申诉单 | 高危 | 本地落盘 | 5000ms |

## 二、工具契约卡（每个工具一份）

### T1 get_vehicle_profile

| 字段 | 内容 |
|---|---|
| 名称 | get_vehicle_profile |
| 描述 | **何时该用**：需要判断保修期、核对车辆基础信息时。<br>**何时不该用**：用户没给 VIN，或只问条款内容不涉及具体车辆时，不要调用。 |
| 参数 | 见下表 |
| 返回 | 车型、购车日期、里程（公里）、使用性质（personal / operating）与基准日期；失败返回 error 对象 |
| 副作用等级 | 只读 |
| 幂等 | 键字段：N/A；去重窗口：N/A |
| 权限 | 角色：售后顾问；租户隔离：示例为单租户，真实接入按会话所属经销商行级隔离 |
| 错误语义 | not_found（VIN 不在档案，建议核对后重试）/ invalid_argument（格式不符，按 17 位且不含 I/O/Q 重填）/ internal_error（不可重试，转人工） |
| 超时 | 单次 3000ms；可重试：是，最多 2 次（仅 timeout / upstream_error） |
| 人工确认 | 不需要 |
| 来源 | 本地实现（data/vehicles.json） |

| 参数 | 类型 | 必填 | 约束 | 示例 |
|---|---|---|---|---|
| vin | string | 是 | 17 位，不含 I / O / Q | LSVAA1234R1234567 |

### T2 query_warranty_period

| 字段 | 内容 |
|---|---|
| 名称 | query_warranty_period |
| 描述 | **何时该用**：已拿到 VIN 与零部件名称、需要判断「在不在保」时。<br>**何时不该用**：还没确认 VIN 或零部件名称时先追问；只问条款原文时改用 search_clause。 |
| 参数 | 见下表 |
| 返回 | in_warranty 结论、剩余天数（负数即超期）、超限原因、条款出处 |
| 副作用等级 | 只读 |
| 幂等 | 键字段：N/A；去重窗口：N/A |
| 权限 | 角色：售后顾问；租户隔离同车辆档案 |
| 错误语义 | not_found（无该零部件规则）/ invalid_argument（零部件不在枚举内，取可用值重填）/ timeout（可重试）/ internal_error（转人工） |
| 超时 | 单次 3000ms；可重试：是，最多 2 次 |
| 人工确认 | 不需要 |
| 来源 | 本地实现（data/vehicles.json + data/warranty_rules.json） |

| 参数 | 类型 | 必填 | 约束 | 示例 |
|---|---|---|---|---|
| vin | string | 是 | 17 位，不含 I / O / Q | LSVAA1234R1234567 |
| part_name | string | 是 | 固定枚举 | 变速箱 |

### T3 search_clause

| 字段 | 内容 |
|---|---|
| 名称 | search_clause |
| 描述 | **何时该用**：需要在答复里给出条款依据、或确认某类故障是否属三包范围时。<br>**何时不该用**：只需车辆信息或保修期结论时不要调用。 |
| 参数 | 见下表 |
| 返回 | hits 列表（chunk_id / source / title / text），最多 top_k 条；hits 为空表示未查到，不得编造 |
| 副作用等级 | 只读 |
| 幂等 | 键字段：N/A；去重窗口：N/A |
| 权限 | 角色：售后顾问；条款库为全租户共享只读资源 |
| 错误语义 | invalid_argument（检索词为空或过长）/ internal_error（不可重试） |
| 超时 | 单次 3000ms；可重试：是，最多 1 次 |
| 人工确认 | 不需要 |
| 来源 | 本地实现（data/clauses.json），真实实现走 RAG 检索 |

| 参数 | 类型 | 必填 | 约束 | 示例 |
|---|---|---|---|---|
| query | string | 是 | 业务名词组合，建议 2~5 个词 | 变速箱 累计修理 |

召回上限 3 条、命中分阈值 3（config/agent.toml:24-25）；低于阈值按未命中处理，不得编造条款。

### T4 submit_appeal_ticket

| 字段 | 内容 |
|---|---|
| 名称 | submit_appeal_ticket |
| 描述 | **何时该用**：判定结论为在保可赔、且售后顾问明确要求建单时。<br>**何时不该用**：结论未定、需人工复核、或用户只是咨询时，一律不要调用。 |
| 参数 | 见下表 |
| 返回 | ticket_id 与 status；重复提交同一业务返回首次工单号，不新建 |
| 副作用等级 | 高危（写且不可逆） |
| 幂等 | 键字段：session_id + tool + biz_key（biz_key = vin\|part_name\|appeal_type，不含步序）；去重窗口 7200s |
| 权限 | 角色：售后顾问；租户取自会话，按经销商隔离 |
| 错误语义 | approval_required（未人工确认，不可重试）/ permission_denied（越权，转人工）/ invalid_argument（参数不符）/ internal_error（转人工） |
| 超时 | 单次 5000ms；可重试：否（写操作不自动重试，靠幂等键防重） |
| 人工确认 | 必需（令牌绑定工具名与参数指纹，30 分钟过期） |
| 来源 | 本地实现（写 runtime/tickets/），真实实现调工单系统 |

| 参数 | 类型 | 必填 | 约束 | 示例 |
|---|---|---|---|---|
| vin | string | 是 | 17 位，不含 I / O / Q | LSVAA1234R1234567 |
| part_name | string | 是 | 固定枚举 | 变速箱 |
| appeal_type | string | 是 | 固定枚举 | 三包维修 |
| description | string | 是 | ≤ 200 字，一句话说明故障与已处理动作 | 低速换挡异响，已进店检查未拆解 |

## 三、工具选择策略（工具数 > 15 时必填）

| 项 | 内容 |
|---|---|
| 策略 | 不适用：4 个工具全量注入 |
| 分组规则 | 预留 group 字段（warranty / clause / appeal），当前仅用于日志归类 |
| 选择结果如何校验 | 每个样本断言 expect.tools_used；越界调用由注册表返回 not_found 与可用清单 |
