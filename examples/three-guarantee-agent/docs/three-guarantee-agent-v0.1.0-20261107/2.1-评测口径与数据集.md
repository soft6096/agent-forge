## 一、数据集分层

| 层 | 文件路径 | 样本数 | 覆盖范围 | 何时跑 |
|---|---|---|---|---|
| 冒烟集 | evals/smoke/*.json | 12 | 主路径、五类终止、工具错误、人工确认、上下文降级 | 每次改动 |
| 回归集 | 未建 | 0 | — | 每次提交（当前缺） |
| 黄金集 | 未建 | 0 | — | 版本对比（当前缺） |
| 对抗集 | 未建 | 0 | 注入 / 诱导 / 越权边界（当前缺） | 上线前 |
| 负样本集 | evals/negative/01-expect-mismatch.json | 1 条 7 断言 | 判定器自检：断言故意写错，跑红是预期 | 改判定逻辑后 |

分层理由：负样本集证明"判定器真的会红"，不能替代对抗集——前者验证评测工具，后者验证 agent 抗攻击。

## 二、样本编写规范

字段以 runner 实际解析为准（src/tga/eval/cases.py），比通用模板更具体：

| 字段 | 说明 | 是否必填 |
|---|---|---|
| id | 全局唯一，与文件名一致 | 必填 |
| input | 用户原始输入，保留真实表述 | 必填 |
| note | 本条覆盖什么，失败时直接进报告 | 建议 |
| expect.reason | 期望终止原因，限定五类之一 | 必填 |
| expect.max_steps | 允许的最大步数，超出算失控 | 必填 |
| expect.tools_used | 期望调用过的工具，按包含判定 | 选填 |
| expect.answer_contains / answer_not_contains | 答复必须出现 / 不得出现的片段 | 选填 |
| expect.detail_contains | 终止说明必须出现的片段 | 选填 |
| expect.tool_error_codes | 期望错误码，集合相等判定 | 选填 |
| cancel_before_run | 开跑前置中断标志，覆盖 cancelled 分支 | 选填 |
| context_override | 用例级上下文预算覆盖，仅用于构造极端场景 | 选填 |
| requires_recording | 是否需要回放录制，纯终止分支可免 | 选填 |
| confirm_pending | 跑完后模拟人工确认，验证开闸通道 | 选填 |

加载期强校验：reason 不在五类内、context_override 键名或类型不对、目录为空，一律报错退出，不允许静默跑成"零失败全绿"。

## 三、指标口径

| 指标 | 定义 | 计算方式 | 基线值 | 门禁阈值 |
|---|---|---|---|---|
| 任务通过率 | 断言全过的样本占比 | 通过样本 / 总样本 | 100%（12/12） | ≥ 80%，且冒烟集必须 100% |
| 平均步数 | 单任务模型-工具往返轮次 | 各样本 steps 算术平均 | 2.33（序列 2,2,3,2,2,1,8,3,1,1,1,2） | ≤ 8（等于配置上限） |
| 单任务 token | usage.total_tokens | 主程序汇总 | 2180（只读主路径单样本） | ≤ 60000 |
| 单任务成本 | 按配置单价折算 | tokens × 单价 | 0.00228 元（同上） | ≤ 0.5 元 |
| 工具选择正确率 | 期望工具与实际调用一致 | 样本级人工/规则判定 | 未单列 | 当前不设阈值 |
| P95 时延 | 端到端耗时 | 需真实模型环境 | replay 下不适用 | 真实环境 ≥ 20 次采样后再定 |

时延与工具正确率暂不设阈值的理由：replay 回放的时延无意义，样本量 12 条算不出 P95；这两项必须在接真实模型后补测，不得用假数据填表。工具正确率当前由 expect.tools_used 间接覆盖。

## 四、判定方式

| 项 | 内容 |
|---|---|
| 主要判定 | 规则断言（expect.* 逐项匹配，见 src/tga/eval/cases.py） |
| 裁判模型 | 不使用 |
| 评分 rubric | 不涉及（无主观评分项） |
| 一致性抽检 | 不适用（无裁判）；规则断言的一致性由负样本集保证 |
| 已知偏差 | 回放按输入原文匹配，换个说法即命中不到录制——这会低估真实模型能力，属已知偏差，不作为通过率依据 |

| 项 | 内容 |

## 七、反模式自检（出现任一项即打回）

- [ ] 只有「准确率」一个指标，无成本与时延
- [ ] 全部样本由写码的 agent 自己生成，无人工确认样本
- [ ] 只有一次性验收集，无回归集
- [ ] 用模型裁判但无一致性抽检
- [ ] 门禁阈值未定义或全部写「待定」

逐项核对结论：第 1、4、5 项未命中；第 2 项部分命中（样本由开发构造，缺人工确认黄金集，已记入第五节缺口）；第 3 项命中（回归集未建，已记入缺口）。
