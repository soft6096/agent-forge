## 五、未覆盖项与风险

| 项 | 影响 | 建议 |
|---|---|---|
| 无对抗集（提示词注入样本） | N6 的拦截只有代码路径，无回归样本，改动后回归不到 | 上线前补 3~5 条注入样本，进对抗集 |
| 无回归集与黄金集 | 历史失败样本无法沉淀，只能靠冒烟兜底 | 每次真实失败回填一条回归样本，只增不删 |
| 回放按输入原文匹配 | 换说法即命中不到录制，真实模型能力被低估 | 需要覆盖新说法时先补录制；不得以此判定模型不行 |
| 时延与真实 token 未测 | 成本与时延结论只在 replay 与单样本口径成立 | 接真实模型后至少 20 次采样，再定 P95 与均值阈值 |
